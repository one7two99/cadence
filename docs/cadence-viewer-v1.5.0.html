Cadence Design Philosophy

Cadenza without compromise — minus two thumbs.

Cadence is the Ferris Sweep adaptation of the Cadenza layout. The Sweep has 34 keys (4 thumb keys instead of 6), so two thumb-cluster functions had to be relocated. Everything else — Colemak-DH, Tap Dance HRM, Frequency+Strength symbols, bilateral layer access, the Code & CLI layer, the International layer — is preserved unchanged.

Core principles

1
No inner column for layer content

G and M (the inner-column letters in Colemak-DH) require a lateral inward index movement. They carry only their letters and App/Menu on hold. Never layer content. This rule holds without exception in v1.5.0.

2
Vertical movement only — no lateral stretches

Every layer access uses straight vertical finger movement. Pinky down (Z//), ring down (X/.), middle down (C/,), index down (D/H), middle up (F/U), ring up (W/Y).

3
Strongest finger gets highest priority

Index > Middle > Ring > Pinky. = (rank 1 symbol) sits on T (strongest left index). $ (rank 5) sits on N (strongest right index). AltGr and Meta on weaker fingers.

4
NEIO = ←↓↑→ on directional layers

The N-E-I-O home-row positions carry ←/↓/↑/→ on L2 Navigation. The same finger pattern repeats on L11 Workspaces and L2 word-skip. Once learned, the spatial pattern transfers.

5
No pinky-top holds — with one deliberate exception

Pinky-top holds are uncomfortable and slow. Cadence enforces this strictly. The single exception: L12 Firmware Control on Q and ', with a 500 ms hold. The uncomfortable position plus the long term is a deliberate safety mechanism for functions that must never accidentally trigger.

6
Frequency × Ergonomic quality = access key rank

The most-used layers earn the best key positions. Symbols → right thumb middle (Bsp). International → strongest index pair (D/H). F-Keys → chord (rare, so acceptable). Firmware Control → worst position with longest hold (must never trigger by accident).

Sweep-specific decisions

L6 via thumb chord — The Sweep has no spare thumb for L6 access. Hold Bsp (→ L4) then hold Spc-position (which on L4 is MO(6)) → L6. Order matters: Bsp first, Spc second.

L11/L12 consolidation — Cadenza's split between L11 (WS Quick) and L12 (WS Full) is merged into a single L11 Workspaces layer with the full WS 1–10 numpad map.

Pinky-top promoted to safety gate — The freed L12 slot is reused for a Firmware Control layer. The two outer pinky-top positions (Q, ') become deliberate access keys with a 500 ms hold term.

L12 Firmware Control — destructive layer. QK_BOOT reboots a half into bootloader mode. QK_REBOOT resets a half. The access path (uncomfortable position + 500 ms hold + separate home-row press inside the layer) is intentionally awkward. There are no other keys on L12 — accidental letter input cannot fire while L12 is active.
