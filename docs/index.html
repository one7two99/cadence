Cadence

v1.11.0 — Layout Documentation · Ferris Sweep · Colemak-DH · Vial / QMK

Cadence is a 34-key split keyboard layout for the Ferris Sweep, built on Colemak-DH and configured in Vial. It is the Sweep adaptation of the Cadenza layout (36-key Corne Choc) — same design philosophy, same muscle memory, two thumb keys less.

Cadence v1.11.0 — Design Decisions and Layer Documentation

What's new in v1.11.0 — Mouse-on-thumb redesign solves the v1.9 HRM-blocking issue: bilateral F+U Mouse triggers blocked Ctrl on the active hand. Spc now carries a three-way Tap Dance (tap=Space, hold=Navigation, tap+hold=Mouse), Tab carries a two-way Tap Dance (tap=Tab, hold=International). The deprecated L2 Symbols layer is replaced by a freshly designed L12 — see the dedicated L4-Symbol-Layer.html for that specification. Brackets moved from D+H to X+. for cleaner hold-detection. See the changelog block below for the full migration details.

★ Changelog · v1.8.0 → v1.9.0 — Sonata-aligned release

v1.9.0 reorganizes Cadence's layer system to mirror Sonata v3.0 wherever physically possible. The intent: future migration to Sonata hardware becomes a "learn the new alpha grid" exercise rather than a complete relearning of the layer architecture. Layers L1–L9 now match Sonata's numbering; L10 (Clipboard) and L11 (Firmware Control) are Cadence-only extras.

Other changes

  • Bilateral pair finger-symmetry verified. All five bilateral triggers (F+U, C+,, W+Y, Z+/, D+H) use the same finger on both hands in the same row.
  • L10 Clipboard intentionally has no access key. User does not currently use clipboard macros. Layer remains in firmware for future activation.
  • X and . keys lose their MO holds. Both were L9 Code & CLI triggers in v1.8.0; now they are pure letter keys with no hold function.
  • Sonata-compatibility note. Layers L0–L8 now match Sonata v3.0's numbering and layer roles. The Cadence-specific extras (L9 Brackets, L10 Clipboard, L11 Firmware) live above Sonata's range.
  • Inner column rule verified. All 12 modal layers continue to leave the inner column (G/M positions) empty per Cadence's "no inner column for layer content" design rule.

Migration notes for users coming from v1.8.0

  • Thumb mapping changes. Spc no longer triggers Navigation; it now triggers Overflow+International (L1). Tab triggers Navigation (L4). Bsp and Ent are unchanged.
  • The two-thumb chord for F-Keys is gone. F-Keys are now part of L6 Fn+Media, accessed via C+, bilateral hold.
  • Brackets moved from C+, to D+H. If you had Brackets-related muscle memory on the middle-bottom positions, it now lives on index-bottom.
  • Tapping-term tuning recommended for D+H. Both D and H are common letters (~5% frequency each). With the default 200 ms tapping term, occasional false-positive hold detection is likely during normal typing of words like "und", "der", "hat". Increase to 220–250 ms or rely on HOLD_ON_OTHER_KEY_PRESS.
  • Expected adaptation period: 2–3 weeks of daily typing for the new triggers to feel natural. The first week will feel ~30% slower with frequent layer-trigger errors; week two stabilizes; week three should match or exceed v1.8 typing speed.

L12 Symbols — completely redesigned

L12 replaces the deprecated L2 with a freshly designed symbol layout shared across Cadence (Sweep) and Sonata (28-key). Key principles:

  • Access asymmetry. Bsp activates the layer with the right thumb, anchoring the right hand. High-frequency symbols are placed on the freer left hand and on top rows of the right hand; the right bottom row is left transparent (worst region during right-thumb anchoring).
  • Frequency × strength. Symbols ranked by daily-usage frequency are assigned to fingers in strength order, weighted by the position-quality penalty for the anchored right hand.
  • Tap Dance pairs for related symbols: ! / & on S, * / @ on T, / / \ on D, plus bracket pairs (/), [/], {/}, </> on the right top row.
  • Operators on thumbs: - on Spc-thumb, = on Tab-thumb (most-frequent operators on strongest positions).

See the dedicated L4-Symbol-Layer.html document for the full design rationale, position assignments, and migration history. The "L4" in the filename refers to the abstract Symbol-Layer concept; in Cadence v1.11 it is implemented as L12.

Migration notes for users coming from v1.9.0

  • Spc and Tab swap their primary layer roles. Spc now → Navigation (was Tab), Tab now → International (was Spc). Mental shift: think "Spc = cursor work, Tab = special characters".
  • Mouse via Spc tap+hold. Tap Spc, then immediately press Spc again and hold. This two-step pattern is unique to Mouse and avoids accidental activation during normal typing. Slightly slower to activate than v1.9's hold (~300ms vs ~200ms) but eliminates HRM conflicts.
  • Brackets moved to X+. (Ring Bottom). If you had bracket muscle memory on D+H, retrain — and notice that hold-detection feels more reliable because X and . are far less frequent than D and H.
  • Symbol layer rebuilt. The old L2 layout is invalidated; learn the new L12 layout via the dedicated documentation. Symbol positions for thumbs (- on Spc, = on Tab) are unchanged.
  • Repeated Tab works inside Navigation (Spc-hold) and Code & CLI (W/Y-hold) layers via Ent-thumb. Use those layers for multi-Tab workflows.
  • F and U lose their MO holds. They are now triggers for L6 Fn+Media (instead of v1.9's L5 Mouse). Watch out: muscle memory of "F-hold = Mouse" needs to retrain to "F-hold = Fn-Keys".
  • D and H lose their MO holds. They are now plain letter keys (no more L9 Brackets or other layer trigger). Bracket activation moved to X and . instead.

Design Principles

1. No inner column for layer content

The inner column (G/M in Colemak-DH) requires a lateral inward index movement. G and M carry only their base letters plus App/Menu on hold. Never layer content. This rule holds without exception through v1.11.0.

2. Vertical movement only — no lateral stretches

Every layer access key requires straight vertical finger movement. Pinky down (Z//) → L7. Ring down (X/.) → L9. Middle down (C/,) → L8. Index down (D/H) → L10. Middle up (F/U) → L11. Ring up (W/Y) → L1.

3. Strongest finger gets highest priority

Index > Middle > Ring > Pinky. = (rank 1 symbol) sits on T. $ (rank 5) sits on N. AltGr and Meta on weaker fingers.

4. NEIO = ←↓↑→ on directional layers

The N-E-I-O home row positions carry ←/↓/↑/→ on L2 Navigation. The same pattern repeats on L11 Workspaces and L2 word-skip. Once learned, the spatial pattern transfers automatically.

5. No pinky-top holds — with one deliberate exception

Cadence enforces this rule strictly. The single exception: L12 Firmware Control on Q and ', with a 500 ms hold. The uncomfortable position plus the long hold serves as a deliberate safety mechanism for functions that must never accidentally trigger.

6. Frequency × Ergonomic quality = access key rank

The most-frequently-used layers earn the best key positions. Symbols (L4) → right thumb middle (Bsp). International (L10) → strongest index pair (D/H). F-Keys (L6, rare) → chord. Firmware Control (L12, very rare) → worst position with longest hold.

Bilateral pair finger-symmetry

The remaining bilateral letter-pair triggers in v1.11.0 are finger-symmetric: the left-hand and right-hand triggers are played by the same finger on both hands, in the same row. The brain learns "Code = both ring fingers, top row" rather than memorizing two separate positions.

The Spc Tap-Hold pattern (v1.11 highlight)

TD(21) on Spc carries three distinct functions on a single key:

  • Spc tap → Space (normal word separator)
  • Spc hold → MO(4) Navigation (arrows, word jumps, page navigation)
  • Spc tap + hold → MO(5) Mouse (cursor, scroll, mouse buttons)

The tap+hold action triggers when Spc is tapped, then immediately pressed again and held. This three-way differentiation eliminates v1.9's HRM-blocking issue: on Mouse, both hands are free to use Home Row Mods (Ctrl for multi-select, Shift for range-select).

The Tab Tap-Hold pattern

TD(10) on Tab provides:

  • Tab tap → Tab (normal indent / form navigation)
  • Tab hold → MO(1) International (umlauts, ß, €, dead-key quotes)

Tab is also placed as a regular key on the Ent-thumb position of L4 Navigation and L7 Code & CLI, so repeated Tab sequences (multi-line indentation, shell auto-completion, form navigation) work without leaving the active layer.

L12 Symbols Hold Bsp

New symbol layer introduced in v1.11.0, replacing the deprecated L2. Designed under the principle of access asymmetry: Bsp activates the layer with the right thumb, anchoring the right hand. Symbols ranked by daily-usage frequency are placed on the freer left hand and on top rows of the right hand; the right bottom row is intentionally left transparent (worst region during right-thumb anchoring). Left home holds the most-frequent operators (% + ! * with ! and * as Tap Dance for & and @ on hold). Right top carries bracket pairs as Tap Dance. - on Spc-thumb, = on Tab-thumb. Specification shared with Sonata v3.x for muscle-memory continuity. See the dedicated L4-Symbol-Layer.html for the full design rationale.

On dead-key keyboard layouts (US-International, German with dead keys), pressing apostrophe or quote alone produces no output until the next keystroke. These macros explicitly type the apostrophe + space to commit the character.

Firmware Notes

Vial-QMK build

Cadence v1.11.0 uses 54/64 Tap Dance slots. The standard Vial-Sweep firmware build ships with 48 entries — a custom build with TAP_DANCE_ENTRIES = 64 is required for v1.8 because TD(50) is now occupied.

Set in keyboards/ferris/sweep/keymaps/vial/config.h:

#define TAP_DANCE_ENTRIES 64

Mouse / scroll settings

The Vial settings section in v1.11.0 contains tuned QMK settings (unchanged from v1.5.0–v1.9.0). The values are stored as numeric Vial setting IDs that depend on the specific firmware build. Documenting the semantic mapping is on the v2.0 ROADMAP.

OS keyboard layout

Set the OS keyboard layout to US International. Required for:

  • RAlt+S → ß
  • RAlt+5 → €
  • RAlt+Q/Y/P → ä/ü/ö (and Shift+RAlt+Q/Y/P → Ä/Ü/Ö, used by L10 hold-macros M16/M17/M18)
  • " dead key (Shift+Quote) → ä/ö/ü when followed by a vowel

Loading the layout

Open Vial → File → Load saved layout → select configuration/Cadence-FerrisSweep_v1_8_0.vil.

Recovery

If the keyboard becomes unresponsive: enter the bootloader by holding Q for 500 ms (left half) or ' for 500 ms (right half), then press the S-position (QK_BOOT). The half will appear as a USB drive; drop the .uf2 firmware file onto it.
