Cadence

v1.5.0 — Layout Documentation · Ferris Sweep · Colemak-DH · Vial / QMK

Cadence is a 34-key split keyboard layout for the Ferris Sweep, built on Colemak-DH and configured in Vial. It is the Sweep adaptation of the Cadenza layout (36-key Corne Choc) — same design philosophy, same muscle memory, two thumb keys less.

What is different from Cadenza

The Ferris Sweep has 34 keys (30 alpha + 4 thumb) versus the Corne Choc's 36 (30 alpha + 6 thumb). The two missing thumb keys force three structural decisions, which then cascade into layer-content adjustments.

Everything else — Colemak-DH base, Tap Dance HRM, all bottom-row layer access keys, Frequency+Strength symbols, bilateral access on L7/L8/L9/L10/L11, the Code & CLI macros, the International dead-key layer — is preserved unchanged.

The Sweep adaptation is not a downgrade. It removes redundant features (RGB on a non-RGB board, two near-identical WM layers) and replaces dedicated thumb keys with chord-based access that costs nothing in muscle memory. Anyone familiar with Cadenza will find Cadence immediately usable.

Why Cadence over standard Miryoku

Miryoku is an excellent baseline. Cadence (via Cadenza) keeps Miryoku's core insight (layers via thumb holds, HRM on home row) and replaces the parts that don't serve the specific use case.

Design Principles

1. No inner column for layer content

The inner column (G/M in Colemak-DH) requires a lateral inward index movement — one of the most strain-inducing motions on a keyboard. G and M carry only their base letters plus App/Menu on hold (TD4/TD5). Never layer content. This is the same insight behind the Colemak-DH modification itself. This rule holds without exception in v1.5.0.

2. Vertical movement only — no lateral stretches

Every layer access key requires straight vertical finger movement. No diagonal, no lateral. Middle finger down (C/comma) → L8. Ring finger down (X/period) → L9. Pinky down (Z/slash) → L7. Middle finger up (F/U) → L11. Ring finger up (W/Y) → L1. Index finger down (D/H) → L10.

3. Strongest finger gets highest priority

Index > Middle > Ring > Pinky. On every row, the most important symbol goes to the strongest available finger. = (rank 1 symbol) sits on T (strongest left index). $ (rank 5) sits on N (strongest right index). AltGr and Meta go to weaker fingers.

4. NEIO = ←↓↑→ on directional layers

The N-E-I-O home row positions on the right hand carry ←/↓/↑/→ on L2 Navigation. The same finger positions repeat on L11 Workspaces for focus switching (⌘+arrow) and on the bottom row for window movement (⌘⇧+arrow). The Top Row Ctrl+Arrow on L2 follows the same convention. Once learned, the spatial pattern transfers automatically.

5. No pinky-top holds — with one deliberate exception

Holding a pinky-top key is uncomfortable and slow. Cadence enforces this rule strictly with one explicit exception: L12 Firmware Control. The Q (left pinky top) and ' (right pinky top) carry a 500 ms hold to MO(12). The uncomfortable position combined with the unusually long hold term serves as a deliberate safety mechanism for functions that must never trigger by accident (QK_BOOT, QK_REBOOT).

6. Frequency × Ergonomic quality = access key rank

The most-frequently-used layers earn the best key positions. Symbols (L4) gets the right thumb middle (Bsp) — no lateral movement. International (L10) gets the index pair (D/H) — strongest fingers. F-Keys (L6, rare) gets the chord — acceptable because rarely needed. Firmware Control (L12, very rare) gets the worst position with the longest hold — exactly because it must never trigger by accident.

Layer Reference

L0 Base Always active

Colemak-DH base with Home Row Mods via Tap Dance.

Left HRM: A=⌘ (250 ms · TD0) · R=⌥ (200 ms · TD1) · S=⌃ (200 ms · TD2) · T=⇧ (200 ms · TD3) · G=RGui (200 ms · TD4 · inner column).

Right HRM: M=App/Menu (TD5 · inner column) · N=⇧ (TD6) · E=⌃ (TD7) · I=AltGr (TD8) · O=⌘ (250 ms · TD9).

Top-row holds: W/Y → L1 Media (TD11/TD23, ring top) · F/U → L11 Workspaces (TD14/TD22, middle top) · Q/' → L12 Firmware Control (TD46/TD47, pinky top, 500 ms hold).

Bottom-row holds: Z// → L7 Clipboard (TD12/TD13, pinky bottom) · X/. → L9 Code & CLI (TD15/TD20, ring bottom) · C/, → L8 Brackets (TD16/TD19, middle bottom) · D/H → L10 International (TD17/TD18, index bottom).

Thumb LTs: Spc → L2 Navigation · Tab → L3 Mouse · Ent → L5 Numbers · Bsp → L4 Symbols.

L6 access: Hold Bsp (→ L4) then Hold Spc-position (→ MO(6)) — chord activation. The order matters; Bsp first, Spc second. The reverse order produces a literal Backspace.

L key: No hold function in Cadence. L is plain KC_L.

L4 Symbols Hold Bsp

Symbols ranked by daily usage frequency in German IT writing, then assigned to fingers in strength order.

Left home row: # (A) · _ (R) · ! (S) · = (T, rank 1, strongest finger).

Right home row: $ (N, rank 5) · @ (E) · % (I) · & (O).

Left bottom row: ` (Z, pinky) · ~ (X) · + (C) · : (D).

Right bottom row: * (H) · ^ (comma) · ; (period) · / (slash). The plain / here allows typing */ or // patterns without leaving L4.

Left thumb Spc-position: MO(6) — chord-activation key for L6 F-Keys.

Left thumb Tab-position: − (KC_MINUS) — frequently needed for German compound words.

L10 International Hold D or Hold H

International characters with bilateral access for German typing.

Left home row: € (R-position, AltGr+5) · ß (S-position, AltGr+S) · TD33 (T-position): tap = " dead key, hold = " literal (via macro M4 with trailing space).

Right home row: TD33 (N-position, mirror of T) · ' (E-position, plain quote) · TD34 (I-position): tap = M2 (' literal with space), hold = M3 (triple quote).

Bilateral umlaut access: the " dead key on both T and N means ä/ö/ü works regardless of which hand triggered the layer (Hold D activates from the left, Hold H activates from the right).

ß and €: direct RAlt keycodes — no macros needed.

L12 Firmware Control Long-hold (500 ms) Q or '
⚠ Destructive layer. L12 contains firmware-control commands. Triggering QK_BOOT reboots the keyboard half into bootloader mode (USB drive); triggering QK_REBOOT resets the half. The access path is deliberately uncomfortable to prevent accidents.

Access: Long-hold (500 ms) Q (left pinky top, TD46) or long-hold ' (right pinky top, TD47). The 500 ms term is more than double the standard 200 ms — the position is uncomfortable on purpose.

Left home row: S-position (middle) = QK_BOOT · T-position (index) = QK_REBOOT.

Right home row: N-position (index) = QK_REBOOT · E-position (middle) = QK_BOOT.

Both functions are mirrored on both hands. Once on the layer, a deliberate second key press is still required — there is no key on L12 that triggers immediately on layer entry. The combination of the awkward access plus the home-row position serves as a two-step safety mechanism.

Other than QK_BOOT / QK_REBOOT, the entire layer is empty — no accidental letter input can fire while L12 is active.

Firmware Notes

Vial-QMK build

Cadence v1.5.0 uses 46/48 Tap Dance slots. The standard Vial-Sweep firmware build supports at least 48 Tap Dance entries, so no custom firmware is typically required. If you build the firmware yourself, verify TAP_DANCE_ENTRIES >= 48 in config.h.

Mouse / scroll settings

The Vial settings section in v1.5.0 contains tuned QMK settings (mouse acceleration, scroll behaviour, etc.). The values are stored as numeric Vial setting IDs that depend on the specific firmware build. They are preserved automatically when the .vil file is loaded into a matching firmware. Documenting the semantic mapping (which numeric ID = which QMK setting) is on the v1.5.x ROADMAP.

OS keyboard layout

Set the OS keyboard layout to US International. Required for:

  • RAlt+S → ß
  • RAlt+5 → €
  • Dead key " (Shift+Quote) → ä, ö, ü when followed by a vowel

Loading the layout

Open Vial → File → Load saved layout → select configuration/Cadence-FerrisSweep_v1_5_0.vil.

Recovery

If the keyboard becomes unresponsive: enter the bootloader by holding Q for 500 ms (left half) or ' for 500 ms (right half), then press the S-position (QK_BOOT). The half will appear as a USB drive; drop the .uf2 firmware file onto it. If only a soft reset is needed, use QK_REBOOT (T-position) instead.
