Cadence

v1.8.0 — Layout Documentation · Ferris Sweep · Colemak-DH · Vial / QMK

Cadence is a 34-key split keyboard layout for the Ferris Sweep, built on Colemak-DH and configured in Vial. It is the Sweep adaptation of the Cadenza layout (36-key Corne Choc) — same design philosophy, same muscle memory, two thumb keys less.

v1.8.0 Colemak-DH 13 active layers Tap Dance HRM Code & CLI Tiling WM Direct umlauts Firmware Control 49/64 TD · 19/32 Macros Vial / QMK · 34 keys
Cadenza without compromise — minus two thumbs.

Cadence v1.8.0 — Design Decisions and Layer Documentation

What's new in v1.8.0 — direct AltGr-based umlaut access on L10. Three new Tap Dances (TD48/49/50) on the A/U/O positions: tap = ä/ü/ö, hold = Ä/Ü/Ö (via macros M16/M17/M18). The existing " dead-key path is unchanged. Firmware now requires TAP_DANCE_ENTRIES = 64.

What is different from Cadenza

The Ferris Sweep has 34 keys (30 alpha + 4 thumb) versus the Corne Choc's 36 (30 alpha + 6 thumb). The two missing thumb keys force three structural decisions:

Why Cadence over standard Miryoku

Cadence (via Cadenza) keeps Miryoku's core insight (layers via thumb holds, HRM on home row) and replaces the parts that don't serve the specific use case.

Design Principles

1. No inner column for layer content

The inner column (G/M in Colemak-DH) requires a lateral inward index movement. G and M carry only their base letters plus App/Menu on hold. Never layer content. This rule holds without exception in v1.8.0.

2. Vertical movement only — no lateral stretches

Every layer access key requires straight vertical finger movement. Pinky down (Z//) → L7. Ring down (X/.) → L9. Middle down (C/,) → L8. Index down (D/H) → L10. Middle up (F/U) → L11. Ring up (W/Y) → L1.

3. Strongest finger gets highest priority

Index > Middle > Ring > Pinky. = (rank 1 symbol) sits on T. $ (rank 5) sits on N. AltGr and Meta on weaker fingers.

4. NEIO = ←↓↑→ on directional layers

The N-E-I-O home row positions carry ←/↓/↑/→ on L2 Navigation. The same pattern repeats on L11 Workspaces and L2 word-skip. Once learned, the spatial pattern transfers automatically.

5. No pinky-top holds — with one deliberate exception

Cadence enforces this rule strictly. The single exception: L12 Firmware Control on Q and ', with a 500 ms hold. The uncomfortable position plus the long hold serves as a deliberate safety mechanism for functions that must never accidentally trigger.

6. Frequency × Ergonomic quality = access key rank

The most-frequently-used layers earn the best key positions. Symbols (L4) → right thumb middle (Bsp). International (L10) → strongest index pair (D/H). F-Keys (L6, rare) → chord. Firmware Control (L12, very rare) → worst position with longest hold.

L10 International v1.8.0 · 3 new TDs Hold D or Hold H

German umlauts, ß and €. Bilateral access — hold D or H to activate.

v1.8.0 — direct umlaut TDs: TD(48) on A → ä (tap) / Ä (hold) · TD(49) on U → ü / Ü · TD(50) on O → ö / Ö. Mnemonically placed on the A / U / O positions.

Hold uses macro (M16 / M17 / M18) because Tap Dance hold slots take a single keycode but capital umlauts require RShift+RAlt+letter.

Left home row R / S: RAlt+5 → € · RAlt+S → ß.

Dead-key fallback: TD(33) on T (left) and N (right) — tap = ", hold = "+space (typing "a, "o, "u produces ä, ö, ü on US-International).

Right home row I / E: TD(34) ' / ''' · literal ' (E-position).

L12 Firmware Control Long-hold (500 ms) Q or '

Bootloader and reboot — deliberately uncomfortable to prevent accidental triggering.

Access: 500 ms hold on Q (left pinky top, TD46) or ' (right pinky top, TD47). The 500 ms term is more than double the standard 200 ms.

Layer content: QK_BOOT and QK_REBOOT placed symmetrically on home-row middle positions, mirrored on both hands.

This is the only intentional pinky-top hold in the entire layout. The combination of an uncomfortable position, a long hold term, and a separate home-row press is the safety mechanism.

Firmware Notes

Vial-QMK build

Cadence v1.8.0 uses 49/64 Tap Dance slots. The standard Vial-Sweep firmware build ships with 48 entries — a custom build with TAP_DANCE_ENTRIES = 64 is required for v1.8 because TD(50) is now occupied.

Set in keyboards/ferris/sweep/keymaps/vial/config.h:

#define TAP_DANCE_ENTRIES 64

Mouse / scroll settings

The Vial settings section in v1.8.0 contains tuned QMK settings (unchanged from v1.5.0). The values are stored as numeric Vial setting IDs that depend on the specific firmware build. Documenting the semantic mapping is on the v1.8.x ROADMAP.

OS keyboard layout

Set the OS keyboard layout to US International. Required for:

  • RAlt+S → ß
  • RAlt+5 → €
  • RAlt+Q/Y/P → ä/ü/ö (and Shift+RAlt+Q/Y/P → Ä/Ü/Ö, used by L10 hold-macros M16/M17/M18)
  • " dead key (Shift+Quote) → ä/ö/ü when followed by a vowel

Loading the layout

Open Vial → File → Load saved layout → select configuration/Cadence-FerrisSweep_v1_8_0.vil.

Recovery

If the keyboard becomes unresponsive: enter the bootloader by holding Q for 500 ms (left half) or ' for 500 ms (right half), then press the S-position (QK_BOOT). The half will appear as a USB drive; drop the .uf2 firmware file onto it.
