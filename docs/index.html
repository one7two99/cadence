Cadence

v1.5.0 — Layout Documentation · Ferris Sweep · Colemak-DH · Vial / QMK

Cadence is a 34-key split keyboard layout for the Ferris Sweep, built on Colemak-DH and configured in Vial. It is the Sweep adaptation of the Cadenza layout (36-key Corne Choc) — same design philosophy, same muscle memory, two thumb keys less.

What is different from Cadenza

The Ferris Sweep has 34 keys (30 alpha + 4 thumb) versus the Corne Choc's 36 (30 alpha + 6 thumb). The two missing thumb keys force three structural decisions, which then cascade into layer-content adjustments.

Everything else — Colemak-DH base, Tap Dance HRM, all bottom-row layer access keys, Frequency+Strength symbols, bilateral access on L7/L8/L9/L10/L11, the Code & CLI macros, the International dead-key layer — is preserved unchanged.

The Sweep adaptation is not a downgrade. It removes redundant features (RGB on a non-RGB board, two near-identical WM layers) and replaces dedicated thumb keys with chord-based access that costs nothing in muscle memory.

Why Cadence over standard Miryoku

Miryoku is an excellent baseline. Cadence (via Cadenza) keeps Miryoku's core insight (layers via thumb holds, HRM on home row) and replaces the parts that don't serve the specific use case.

Design Principles

1. No inner column for layer content

The inner column (G/M in Colemak-DH) requires a lateral inward index movement. G and M carry only their base letters plus App/Menu on hold. Never layer content. This rule holds without exception in v1.5.0.

2. Vertical movement only — no lateral stretches

Every layer access key requires straight vertical finger movement. Pinky down (Z//) → L7. Ring down (X/.) → L9. Middle down (C/,) → L8. Index down (D/H) → L10. Middle up (F/U) → L11. Ring up (W/Y) → L1.

3. Strongest finger gets highest priority

Index > Middle > Ring > Pinky. = (rank 1 symbol) sits on T. $ (rank 5) sits on N. AltGr and Meta on weaker fingers.

4. NEIO = ←↓↑→ on directional layers

The N-E-I-O home row positions carry ←/↓/↑/→ on L2 Navigation. The same pattern repeats on L11 Workspaces and L2 word-skip. Once learned, the spatial pattern transfers automatically.

5. No pinky-top holds — with one deliberate exception

Cadence enforces this rule strictly. The single exception: L12 Firmware Control on Q and ', with a 500 ms hold. The uncomfortable position plus the long hold serves as a deliberate safety mechanism for functions that must never accidentally trigger.

6. Frequency × Ergonomic quality = access key rank

The most-frequently-used layers earn the best key positions. Symbols (L4) → right thumb middle (Bsp). International (L10) → strongest index pair (D/H). F-Keys (L6, rare) → chord. Firmware Control (L12, very rare) → worst position with longest hold.

L4 Symbols Hold Bsp

Symbols ranked by daily usage frequency in German IT writing, then assigned to fingers in strength order.

Left home row: # (A) · _ (R) · ! (S) · = (T, rank 1, strongest finger).

Left bottom row: ` (Z) · ~ (X) · + (C) · : (D).

Right bottom row: * (H) · ^ (comma) · ; (period) · / (slash). The plain / here allows typing */ or // patterns without leaving L4.

Left thumb Spc-position: MO(6) — chord-activation key for L6 F-Keys.

Left thumb Tab-position: − (KC_MINUS) — frequently needed for German compound words.

L12 Firmware Control Long-hold (500 ms) Q or '
⚠ Destructive layer. L12 contains firmware-control commands. Triggering QK_BOOT reboots the keyboard half into bootloader mode; triggering QK_REBOOT resets the half. The access path is deliberately uncomfortable.

Access: Long-hold (500 ms) Q (TD46) or long-hold ' (TD47). The 500 ms term is more than double the standard 200 ms.

Left home row: S-position = QK_BOOT · T-position = QK_REBOOT.

Right home row: N-position = QK_REBOOT · E-position = QK_BOOT.

Both functions mirrored on both hands. All other L12 positions are empty — no accidental letter input can fire.

Firmware Notes

Vial-QMK build

Cadence v1.5.0 uses 46/48 Tap Dance slots. The standard Vial-Sweep firmware build supports at least 48 Tap Dance entries, so no custom firmware is typically required.

Mouse / scroll settings

The Vial settings section in v1.5.0 contains tuned QMK settings. The values are stored as numeric Vial setting IDs that depend on the specific firmware build. Documenting the semantic mapping is on the v1.5.x ROADMAP.

OS keyboard layout

Set the OS keyboard layout to US International. Required for RAlt+S → ß, RAlt+5 → €, and the " dead key for ä/ö/ü.

Loading the layout

Open Vial → File → Load saved layout → select configuration/Cadence-FerrisSweep_v1_5_0.vil.

Recovery

If the keyboard becomes unresponsive: enter the bootloader by holding Q for 500 ms (left half) or ' for 500 ms (right half), then press the S-position (QK_BOOT). The half will appear as a USB drive; drop the .uf2 firmware file onto it.
